産業構造 × 事業所密度・雇用密度（全国比較）
Streamlit ダッシュボード

e-Stat（経済センサス）と国勢調査（人口）を用いて、市区町村別の 事業所密度・雇用密度（人口1万人あたり）を可視化するアプリです。
ランキングと散布図により、地域の産業集積を直感的に比較できます。

🚀 機能概要
サイドバー（フィルタ）
都道府県：全国 / 各都道府県

産業（大分類）：総計（全産業）＋産業大分類

指標：事業所密度 / 雇用密度

人口下限（ノイズ抑制）：0〜20,000（デフォルト 5,000）

表示件数（ランキング）：10〜200（デフォルト 50）

表示タブ
■ ランキング
指標の降順で上位 N 自治体を表示

県平均との差（県差）を併記（＋/−）

■ 散布図（県平均ライン）
X 軸：事業所密度

Y 軸：雇用密度

点サイズ：人口

破線：県平均（人口加重平均）

上部メトリクス
対象人口（合計）

県平均 事業所密度

県平均 雇用密度

※県平均・対象人口は 人口下限フィルタ適用前 のデータで計算。

📊 データ仕様
使用ファイル：

コード
data/base_2014_ec_2020_pop_level2.parquet
主なカラム
カラム名	内容
area	市区町村コード（5桁、zfill(5)）
areaName	地域名
sicCode	産業コード（レベル2）
sicName	産業名
@time	年次
establishments	事業所数
employees	従業者数
population	人口
🔧 前処理ロジック（重要）
filter_scope_base() にて以下を実施：

全国行（area == "00000"）を除外

population > 0 のみ採用

県集計行（XX000）を除外

政令指定都市の二重計上対策

市全体（末尾0）と区（末尾1〜）が両方ある場合、市全体を除外

条件：末尾0 かつ 3桁目が1（例：14100）で、同じ先頭4桁の別コードが存在

🧮 総計（全産業）の扱い
産業が「総計（全産業）」の場合、自治体×年次で再集計：

establishments / employees：合計

population：max（同地域なら同値）

→ 密度を再計算

⚠️ 注意事項
人口の小さい自治体は密度が極端になりやすいため、人口下限フィルタの利用を推奨

本アプリは統計の可視化を目的としています。利用・転載時は出典表記にご配慮ください。
